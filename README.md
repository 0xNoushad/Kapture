## ~/kapture

Beautiful video editing in your browser. No downloads, no subscriptions.

- **zooms** — cinematic zoom effects with smooth animations
- **speed** — adjust playback speed per region (0.25x to 4x)
- **trim** — cut out unwanted sections
- **annotations** — text, arrows, images with full styling
- **backgrounds** — wallpapers, gradients, or custom images
- **effects** — motion blur, shadows, border radius
- **export** — 720p to 4K, proper MP4 muxing

<br/>

## ~/quick start

```bash
pnpm install
pnpm dev
```

<br/>

## ~/stack

- **react** + **typescript** + **vite**
- **pixi.js** — gpu-accelerated rendering
- **mediabunny** — mp4 muxing
- **radix ui** — accessible components
- **tailwind** — styling
